# Opsidian Conversation Sync (Chrome Extension)

ChatGPT 대화를 **ON/OFF 상태 기반**으로 캡처해서 Obsidian으로 동기화하는 크롬 익스텐션입니다.

## 이번 업그레이드에서 실사용 기능으로 강화된 점

- **수동 즉시 동기화** 버튼 제공
- **Obsidian 연결 테스트** (팝업/옵션에서 가능)
- 대화 노트 저장 시 **Frontmatter + 본문 자동 생성**
- **인덱스 노트(`ChatGPT/_index.md`) 자동 갱신**
- **데일리 노트(`Daily/YYYY-MM-DD.md`)에 대화 링크 자동 추가**
- 대화 해시를 저장해 **중복 전송 최소화**
- API 요청 **재시도(네트워크 일시 오류 대응)**

## 동작 방식

브라우저 확장 프로그램은 로컬 파일 직접 쓰기에 제약이 있으므로,
Obsidian의 **Local REST API 플러그인**으로 노트를 생성/갱신합니다.

## 설치

1. 이 폴더를 로컬에 준비
2. Chrome에서 `chrome://extensions` 접속
3. 우측 상단 `개발자 모드` ON
4. `압축해제된 확장 프로그램을 로드` → 이 폴더 선택

## 필수 준비

Obsidian에서 Local REST API 플러그인을 설치/활성화하고 API 키를 발급하세요.

## 설정 항목

- `Vault 이름` (필수)
- `대화 저장 폴더` (기본: `ChatGPT`)
- `데일리 노트 폴더` (기본: `Daily`)
- `인덱스 노트 경로` (기본: `ChatGPT/_index.md`)
- `API Base URL` (기본: `http://127.0.0.1:27123`)
- `API Key` (필수)
- `데일리 노트 링크 추가` ON/OFF
- `인덱스 노트 갱신` ON/OFF

## 사용법

1. ChatGPT 페이지에서 확장 팝업 열기
2. `동기화 ON` 클릭
3. 대화가 바뀔 때 자동 업서트
4. 필요하면 `지금 동기화` 버튼으로 강제 동기화
5. `Obsidian 연결 테스트`로 연동 상태 확인
6. 중단하려면 `동기화 OFF`

## 생성되는 노트 예시

- 대화 노트: `ChatGPT/2026-04-25-대화제목.md`
- 인덱스 노트: `ChatGPT/_index.md`
- 데일리 노트: `Daily/2026-04-25.md`

## 알려진 제한

- ChatGPT 웹 UI 구조가 크게 바뀌면 메시지 추출 로직 업데이트가 필요할 수 있습니다.
- 매우 긴 대화는 동기화 요청 크기가 커질 수 있습니다.
